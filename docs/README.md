| Path | Holds |
| --- | --- |

| [chats/](chats/) | Chat transcripts copied by hooks |
| [archive/](archive/) | Evidence, sealed checkpoints, rolled logs |
| specs/&lt;slug&gt;/ | Detail for one large requirement (created on demand) |
