# .agents/

System files, identical in every project that uses this template. Agents read these; the `docs/` folder is where project facts live.

| Path | Holds |
| --- | --- |
| [guides/](guides/) | Quickstart, protocol, structure, host setup — how the workspace works |
| [skills/](skills/) | Step-by-step workflows loaded on demand |
| [template/](template/) | Spec and trial templates, example test parsers |
| [tools/](tools/) | `ws.py` and its modules — the CLI every agent runs |
